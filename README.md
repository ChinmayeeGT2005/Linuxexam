# Student Event Registration Portal

## Project Overview

This project is a Student Event Registration Portal deployed on a Linux server.

Students can:

- Register for an event
- Store their details in MySQL/MariaDB
- Login using registered credentials

## Technologies Used

- AWS EC2
- Linux
- Nginx / Apache
- PHP
- MySQL / MariaDB
- HTML

## Features

- EC2 Instance Setup
- Security Group Configuration
- LAMP/LEMP Installation
- Database Creation
- Student Registration
- User Login
- Invalid Login Testing
- Service and Port Verification
